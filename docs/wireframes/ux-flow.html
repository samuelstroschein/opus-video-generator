Step 2: the direction form

Renders on the canvas, like Claude Design’s “Ask user”. It comes after the research, so the defaults are real (the feature it found, the screenshots it grabbed) and you confirm instead of typing. The one question Claude Design doesn’t ask, and the research says matters most, is the visual style to copy.

Rules for questions

  • At most 5, one screen, all skippable.
  • Research first so defaults come from the site, not from nothing.
  • Ask only what is expensive to get wrong later: what, where, style, hero moment, visuals.
  • Never ask for what the page can infer (brand, tone, audience).
  • A second round only if the user taps “Ask me follow-ups”.

How the form works technically

The agent ends its turn after writing the question set (for example ask.json). The app renders it on the canvas. Submitting sends the answers as the next chat message, and the agent continues. Nothing blocks, so it survives page reloads and works the same in the cloud. This is simpler and sturdier than a tool call that waits for the user.
